四、核心算法：3 组置信空间

目标：给出一组「到什么价格可以高抛 / 低吸」的参考，并用 90% / 80% / 70% 三档表示策略的激进程度。

重要口径：这里的「置信度」不是统计学上的真实概率预测，而是基于历史波动率和压力支撑结构给出的策略激进程度标签——90% 最保守（价位远离现价，难触发但成功后空间大），70% 最激进（价位靠近现价，易触发但容易被震）。输出时必须向用户说明这一点。

4.1 输入变量

  • P：当前价（盘中用实时价，次日用昨日收盘价）
  • S：箱体下沿 / 支撑位（20日低点、斐波那契 61.8% 回撤、VWAP 等取合理最小/最大）
  • R：箱体上沿 / 压力位（20日高点、斐波那契 38.2% 回撤等）
  • ATR：14日真实波幅
  • σ：近20日对数收益率标准差

4.2 盘间动态价位公式

高抛参考价 H(c) = min(R, P + c × ATR)
低吸参考价 L(c) = max(S, P − c × ATR)

其中 c 是随「置信度」变化的波动率乘数：

标签含义波动率乘数 c适用场景
90% 置信保守型1.5只有价格显著偏离箱体才操作，成功率高、触发少
80% 置信平衡型1.0日常做T主用档位
70% 置信激进型0.5波动小的票，贴近现价频繁做T

4.3 抛压/承接评估

  • 抛压：价格接近 R 且量比 >1.5、换手率放大 → 高抛信号增强；若缩量靠近 R → 可能突破，不宜高抛。
  • 承接：价格接近 S 且缩量止跌 / 出现锤子/十字星 → 低吸信号增强；若放量跌破 S → 支撑失效，不宜低吸。

4.4 次日短线预案

用昨日收盘 P_close 替代盘中 P，并加入 K 线形态和隔夜信息修正：

次日高抛参考 H_next(c) = min(R, P_close + c × ATR)
次日低吸参考 L_next(c) = max(S, P_close − c × ATR)

触发条件会根据隔夜/集合竞价再做一次过滤：如果当日是放量长上影线，次日 H 档位成功率下降；如果是缩量十字星，次日 L 档位成功率上升。

五、分时走势模块设计

后端已存在 _fetch_intraday() 可拉取分钟级价格序列（腾讯/东财互备），当前只用于算均价。可扩展为分时分析引擎：

分析项计算逻辑输出建议
分时 VWAP / 均价趋势 计算最新 30 分钟/60 分钟 VWAP 斜率 斜率向上 + 现价>VWAP →「日内偏强，回踩均价可考虑低吸」；斜率向下 →「日内偏弱，反弹宜高抛」
量价背离 价格创新高但成交量未创新高（或相反） 顶背离 →「追涨动能不足，接近压力位分批高抛」；底背离 →「杀跌动能减弱，接近支撑位可试低吸」
早盘/午盘方向 开盘后 30 分钟涨跌幅 + 成交量占昨日全天比例 放量高开高走 →「早盘强势，回调不破均价可跟」；缩量高开低走 →「早盘诱多，反弹宜减仓」
关键放量节点 识别成交量突增且价格未同步突破的异常量柱 放量滞涨 →「抛压显现」；放量止跌 →「承接有力」
现价相对分时均线位置 (P − VWAP) / VWAP × 100% 偏离 >+1% → 超买回归风险；偏离 <−1% → 超跌反弹机会（结合趋势）

八、需要你确认的几个点

1. 三档置信度的定义方式

方案 A（推荐）：用「保守 / 平衡 / 激进」+ 波动率乘数 1.5 / 1.0 / 0.5，不标真实概率。

方案 B：保留 90% / 80% / 70% 标签，但文案明确写成「90% 保守策略」而非「90% 概率」。

你倾向哪种？标签用什么（90/80/70 还是 高/中/低）？

2. 价位的锚定

方案 A（推荐）：高抛 = min(压力位, 现价 + c×ATR)，低吸 = max(支撑位, 现价 − c×ATR)。

方案 B：完全基于现价 ± 固定百分比（如 ±3% / ±5% / ±8%），简单但忽略个股波动差异。

你倾向哪种？

3. 是否引入 MACD / KDJ / 布林带 等基础指标

当前扩展区已有「技术指标速览」但只展示快照。是否把它纳入做T建议的评分体系（如三维投票），还是只做展示？

4. 次日预案的展示时机

方案 A：盘中也显示，但标注为「基于当前价的预演」，收盘后自动刷新为正式次日预案。

方案 B：只在收盘后显示，盘中隐藏或折叠。

5. 是否画分时图

当前页面无分时图。是否增加一条简单的日内折线（价格 + 均价），帮助你看走势？

6. 板块/概念强度

是否需要接入同花顺/东财的板块涨幅数据？对做T成功率影响较大，但会引入新的数据源依赖和延迟。

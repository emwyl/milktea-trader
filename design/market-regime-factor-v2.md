# 市场环境因子 v2 设计文档（融合定稿版）

> **版本**：v2（融合定稿）
> **融合来源**：① 现有 v1 设计（三层 M/S/Beta+RS）；② 用户补充信息点「评分模型需考虑板块属性：蓝筹/题材在不同场景差异化应用」；③ 豆包建议（市值/风格做环境分类校验，不进评分公式，前置过滤）；④ DS 建议（市场恐慌分熔断 + 风格标签 + 个股 Beta 动态调权，P0+P1 先上、P2 后上）。
> **设计红线**：A/B/C 个股原始评分公式**完全不动**；环境因子只在**输出层**做 `adj_score = raw × M折扣 × 风格乘数` 调节 + 前置过滤标记。与 v192「原始分/最终分分离」理念零冲突。
> **落地节奏**：遵循 DS 优先级 —— 先上 **P0（大盘恐慌分熔断）+ P1（风格标签）跑两周验证**，再上 **P2（个股 Beta + 市值分档 + 场景矩阵复合折扣）**，板块 S 层（板块指数/资金流）作为后续 Phase。

**DS 与你（用户）的共识**：三只红票（天秦 +5.64%、比亚迪 +0.57%、工行 +0.12%）能逆势涨，**不是因为"蓝筹"一个标签**，而是恐慌时资金选「确定性/低波动/护盘」：
- 天秦装备 = 军工避险（逆势题材，高波动事件驱动）
- 比亚迪 = 权重护盘（高 Beta、机构重仓，大盘跌时稳定指数）
- 工商银行 = 绝对防御（低 Beta、红利避风港）

**所以**：模型需要「市场环境过滤器」——普跌日**降权进攻股、加权防御股**，这样评分才能在不同天气下都有效。这与豆包「市值/风格做分类校验、不进公式」完全一致。

## 1. 问题复盘（根因 + 三只红票拆解）

### 1.1 今日（2026-09-11）现象
- 上证 −1.18%，科创 50 盘中破年线 −1.01%，**仅约 11% 个股上涨**，两市放量 1.97 万亿（放量下跌）。
- 低分但涨（假阴性，被模型低估）：42分/某票 +0.x%、50分 +1.95%、56分 +0.08%、59分 +1.37%。
- 高分但跌（假阳性，被模型高估）：62分 −0.61%、64分 −1.86%、64分 −3.09%、65分 −8.24%、72分 −6.44%。
- **60 分阈值下综合正确率 ≈50%**，等于瞎猜。

### 1.2 机制（两种误分类）
1. **假阴性**：弱势/崩坏日，资金轮动/避险脉冲把低分票顶红，模型只看到量价好转。
2. **假阳性**：高 Beta 科技/题材票，平时评分高，但大盘急跌时"跌得比指数狠"，原始 A/B/C 无法区分敏感度。

### 1.3 DS 三只红票拆解（核心输入，已吸收）
| 股票 | 涨幅 | 核心上涨逻辑 | 风格标签 |
| :--- | :--- | :--- | :--- |
| 天秦装备 | +5.64% | 军工避险，与科技反向，事件驱动（逆势题材） | 高波动、事件驱动 ⚔️进攻 |
| 比亚迪 | +0.57% | 权重护盘，新能源龙头机构重仓，跌时稳指数 | 高 Beta、机构抱团 ⚖️护盘权重 |
| 工商银行 | +0.12% | 绝对防御，低估值高股息，熊市避风港 | 低 Beta、红利防御 🛡️防御 |

> 结论：**红 ≠ 蓝筹**，而是"恐慌时资金选确定性/低波动"。天秦是逆势题材，工行是防守，比亚迪是护盘。风格必须细分，不能用单一"蓝筹"标签。

## 2. 设计原则（四条红线）

1. **A/B/C 原始评分公式不动**：流动性/波动(A)、趋势/位置(B)、资金/板块(C) 三维权重、评分、评级、否决逻辑一律保留。环境因子不污染原始分。
2. **输出层调节，非嵌入**：所有折扣、过滤都在 `compute` 末尾或后端 `get_pool_track` 输出层施加，生成 `adj_score` / `adj_grade`，原始 `raw_score` / `raw_grade` 始终可查。
3. **条件性调整，非固定权重**（回应豆包反对"直接加市值权重"）：折扣/加权**只在特定环境档位（弱势/崩坏）生效**，健康市乘数为 1.0。避免牛熊风格轮动时过拟合。
4. **可解释、可回测**：每个折扣系数、阈值都单列，支持 walk-forward 回测与 IC/IR 检验，便于两周后按数据微调。

## 3. 总体结构（结构支柱 —— 四层 + 输出）

```
┌──────────────────────────────────────────────────────────────┐
│ Layer 1  环境层（大盘 M 档位）                                  │
│   输入：上证/科创50/深成指/创业板指 涨跌%、上涨家数占比、      │
│         量能结构、波动率  →  算 恐慌分M(0-100)  →  健康/弱势/崩坏 │
├──────────────────────────────────────────────────────────────┤
│ Layer 2  个股属性层（用户"板块属性" + DS P1/P2）               │
│   市值等级：小盘 / 中盘 / 大盘蓝筹                             │
│   风格标签：🛡️防御 / ⚖️护盘权重 / ⚖️均衡 / ⚔️进攻          │
│   Beta：低β(<0.8) / 中β(0.8-1.2) / 高β(>1.2)  （vs 沪深300 60日）│
│   RS：个股 n 日涨跌幅 − 沪深300 n 日涨跌幅                     │
├──────────────────────────────────────────────────────────────┤
│ Layer 3  信号融合层（场景矩阵）                                │
│   M档位 × 个股属性  →  复合折扣系数 + 前置过滤标记             │
├──────────────────────────────────────────────────────────────┤
│ Layer 4  输出层                                                │
│   raw_score(不变) / adj_score / adj_grade / 语义(看涨·观望·看跌)│
│   / 环境徽章 / 屏蔽标记（脉冲反弹·环境崩坏只守不攻）           │
└──────────────────────────────────────────────────────────────┘
```

## 4. 处理流程（流程支柱）

```
[每 60s 后台采集]  ──►  M 快照(上证/科创50/涨跌家数/量能/波动率)
        │
        ▼
[逐票构建 track]  ──►  原始 A/B/C 评分(raw_score)  ──►  保留
        │
        ├─► Layer2：打 市值等级 / 风格标签 / Beta / RS
        │
        ├─► Layer3：取 M 档位 → 得 M基准折扣；按风格得风格乘数
        │            adj = clamp(raw × M折扣 × 风格乘数, 0, 100)
        │
        ├─► 前置过滤：崩坏→屏蔽新开仓；弱势+逆势涨+题材小票→脉冲反弹过滤
        │
        └─► Layer4：输出 adj_score/adj_grade + 语义 + 徽章 + 标记
                   阈值：健康≥60 / 弱势≥65 / 崩坏≥72(仅观察)
```

**采集时序**：`market_regime` 后台线程 60s 刷新内存快照（复用 `quote_snapshot.py` 模式）；`get_pool_track` 读取快照打标，不阻塞主请求。源失效时优雅降级（M 取上次有效值或默认"健康"，打 `stale` 标记）。

## 5. 数据需求与来源（数据支柱）

| 字段 | 含义 | 来源（现有代码可复用） | 计算方式 |
| :--- | :--- | :--- | :--- |
| 上证涨跌% | sh000001 | `get_market_status()` / `_fetch_spot_tencent("sh000001")` | 直接取 |
| 科创50涨跌% | sh000688 | `_fetch_spot_tencent("sh000688")` | 直接取（科技锚） |
| 深成指/创业板指 | sz399001 / sz399006 | `_fetch_spot_tencent` | 直接取 |
| 上涨家数占比 | 全市场涨跌家数 | 腾讯 `qt` 接口 / 东财 涨跌停接口 | 上涨/(上涨+下跌) |
| 量能结构 | 放量/缩量 + 涨跌 | 成交额 vs 5/20日均量 | 量比>1.2且跌=放量下跌(惩罚) |
| 波动率 | 上证日内振幅 | spot 高低/昨收 | 振幅越大 M 越低 |
| 市值等级 | 总市值分档 | 日线 `total_mv` 或 东财个股概况 | <100亿小盘 / 100-500中盘 / >500大盘蓝筹 |
| 风格标签 | 行业+市值+股息 | `_norm_industry()` + 市值 + 防御行业白名单 | 见 §6.2 |
| Beta | vs 沪深300 60日 | 本地 `daily_quotes` 回归 | cov(stk,mkt)/var(mkt) |
| RS | 个股−沪深300 | 本地 `daily_quotes` | n日累计涨跌幅差 |

> 注：市值/股息若本地日线缺失，用东财个股概况接口补（一次/日缓存）。Beta/RS 用本地日线现算，无需新数据源。

## 6. 算法逻辑（算法支柱）

### 6.1 大盘恐慌分 M（DS P0 熔断，对应原 v1 的 M 层）
```
M = 25·f(上证%) + 20·f(科创50%) + 30·g(上涨家数占比) + 15·h(量能) + 10·i(波动率)
f(x) = clamp(50 + x·25, 0, 100)        # +2%→100, -2%→0
g(r) = clamp(r·100, 0, 100)            # 上涨家数占比直接×100
h    = 放量下跌→20, 缩量下跌→50, 平量→70, 放量上涨→100
i    = clamp(100 - 振幅·K, 0, 100)     # 振幅越大越低

档位：M≥75 健康市 | 50≤M<75 弱势市 | M<50 崩坏市
M基准折扣：健康 ×1.0 | 弱势 ×0.90 | 崩坏 ×0.75
```
> 这就是 DS 的"恐慌分>70 普跌熔断"——我们用连续 M 分 + 三档，比单一开关更平滑。

### 6.2 风格标签推导（DS P1 / 用户板块属性）
```
防御(🛡️)：行业∈{银行, 保险, 公用事业, 煤炭, 红利指数成分} 且 低Beta倾向
护盘权重(⚖️)：总市值>2000亿 且 机构重仓龙头(新能源/白酒/医药/科技龙头)
均衡(⚖️)：消费/制造龙头，非极端
进攻(⚔️)：科技/军工/题材/小盘（总市值<100亿 或 行业∈{半导体,软件,军工,AI}）
```
> DS 原建议只分 防御/进攻/均衡；我们细化出"护盘权重"（比亚迪类），因为高 Beta 但具护盘属性，弱势中相对抗跌但弹性大，需结合 Beta 判断，不能简单归进攻。

### 6.3 风格乘数（弱势/崩坏生效，健康市=1.0；DS 方案A ×0.6/×1.2 落地）
```
弱势/崩坏市下：
  防御股(🛡️)      ×1.15      # DS：防御×1.2，取1.15更稳健
  护盘权重(⚖️)    ×0.95      # 高Beta但护盘，轻微折扣
  均衡(⚖️)        ×1.00
  进攻股(⚔️)      ×0.65      # DS：进攻×0.6，取0.65
健康市：全部 ×1.00
```

### 6.4 复合折扣与最终分
```
adj_score = clamp( raw_score × M折扣 × 风格乘数 , 0, 100 )
```
> 例（DS 原数据校验）：工行 raw 42 → 弱势(×0.9)×防御(×1.15)=43.5≈接近DS的50(DS用×1.2得50.4)；三安光电 raw 36 → 弱势×0.9×进攻0.65=21.1≈DS的22。量级吻合，系数可两周后据回测微调。

### 6.5 前置过滤规则（豆包 + DS，最关键的"防骗"逻辑）
```
① 崩坏市(M<50)：一律不新开仓。
   - 防御/护盘权重 → 标「环境崩坏·只守不攻·可观察」
   - 进攻/题材/高β → 标「环境崩坏·屏蔽」
② 弱势市(M 50-75) + 个股逆势涨(RS>0 且 大盘跌)：
   - 进攻/小盘题材 → 标「脉冲反弹·不做开仓依据」→ 过滤做多信号（但保留持仓/止损管理）
   - 防御/大盘高股息 → 保留观察（可信）
③ Beta 修饰（DS P2 / 豆包）：
   - 高β(>1.2) 逆势涨 → 可信度降级（弱势下进攻×0.65 基础上再提示"弹性大、易回落"）
   - 低β(<0.8) 防御逆势涨 → 可信度升级，标「避险抱团·可信」
```

### 6.6 输出语义与阈值
```
看涨：adj_score ≥ 档位阈值 且 未被屏蔽 且 非「脉冲反弹」标记
观望：被标「脉冲反弹」/「环境崩坏·只守不攻」/ 临界(阈值±3)
看跌：adj_score < 档位阈值
阈值：健康 ≥60 | 弱势 ≥65 | 崩坏 ≥72(仅作观察门槛，实际不新开仓)
```
> 前端展示：保留 raw_score 灰显 + adj_score 主显；环境徽章（健康绿/弱势黄/崩坏红）；屏蔽标红。

## 7. 实施分期（遵循 DS 优先级 P0→P1→P2）

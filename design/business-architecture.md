# 散户智能看盘系统 · 业务架构与功能清单（v3）

> 定位：个人学习用 A 股看盘/分析网站。把「专业经验 + 系统规则 + 个人偏好」结合，产出交易模型与操作推荐，帮小散户避风险、提收益。
> 形态路线：网页版（账号密码登录）→ 后期 APP/小程序。数据本地优先、隐私不出本机。
> v3 变更：① 分析输出改为「看板总览+分析中心」双视图；② 大功能模块独立成库、接口引用、全面客制化；③ 风控改为软引导。

---

## 设计总原则（贯穿所有功能）

1. **风险优先（先控风险，再谈收益）· 软引导**：所有功能默认把"风险"放在"收益"之前。每个信号强制带「风险前置」（风险等级、建议仓位上限、止损位），超阈值强烈预警并**建议**降仓，但最终由用户决策（不强制拦截）。看板与复盘消息**先报风险预警，再报机会**；强制止损信号置顶。选股模型默认剔除高风险标的（ST、次新异常、换手异常）。
2. **专业为基、引导决策**：系统先提供**专业建议基础**（指标释义、该看什么），再引导用户基于自身**风险偏好**做决策，而非替用户拍板。
3. **多指标共振、杜绝单一指标**：决策以 N 个独立指标同指一个方向为前提，单指标只作参考。
4. **模块化解耦、接口引用、全面客制化**：选股 / 信号 / 风控 / 通知 / AI 等**大功能模块各自独立成库（包）**，模块间通过**显式接口（Interface/Contract）**引用，不直接耦合。每个模块支持客制化、自定义、参数配置，新方案/新实现可插拔替换。
5. **方案类型 = 接口的参数化实例**：内置「分析模型方案类型」不是写死的 5 个，而是对模块接口的 JSON 参数化配置（选股集+规则集+风控集三件套），用户可套用、可改、可自建。
6. **隐私不出本机**：行情/持仓/规则只存本地；仅对外拉行情 + 后期 LLM/通知。


**模块化解耦要点**：
- 每个模块定义公开接口（如 `Screener` / `SignalEngine` / `RiskAdvisor` / `Notifier` / `AIProvider` 协议），应用层只依赖接口。
- 同一接口可有多个实现（如 `Notifier`：ServerChan / PushPlus / 企业微信 / 邮件；`AIProvider`：DeepSeek / 通义 / 智谱 / 本地 Ollama），运行时按配置切换，互不耦合。
- 「分析模型方案类型」= 一组指向各模块接口实现的参数集（JSON），落库后可改、可自建。
- 新增方案/指标/通道 = 实现接口 + 注册，无需改应用层代码。

## 二、专业建议基础（系统内置，供 UI / AI 引用）

### 2.1 涨跌幅该看什么（关键指标，非单一看数字）— 已自行检索落地
- **相对均线位置（乖离）**：沿 5 日线运行=强势；跌破 10 日线趋势转弱；回踩 20 日线不破=洗盘买点，破位减仓。
- **量能配合（量在价先）**：价涨量增=健康；涨时缩量=动能不足（卖出信号）；高位放天量+高换手=出货。
- **换手率**：热门题材 10%–20% 承接好；>30%–50% 出货风险剧增。
- **是否突破关键位**：前高/前低/箱体上沿下沿。
- **板块联动**：题材/行业是否在线（单打独斗个股风险高）。
- **涨停/跌停纪律（A股 ±10%）**：涨超 7% 未封板=经典短线卖点；大幅高开 6% 后 10–30 分钟不冲板=诱多出货。
- **振幅 / 布林带位置**：触上轨+超买=止盈；触下轨+超卖=低吸。
- **大盘环境过滤**：涨跌家数比定仓位（如 <800 家上涨空仓，2000+ 家 5–7 成）。

### 2.2 通用风控铁律（专业共识，软引导执行）
- **严格止损**：买入前定止损位（亏损 5% 或破关键支撑），触发即预警，禁止"死扛/补仓摊成本"。
- **仓位管理**：单只 ≤2 成、总仓 ≤5 成；盈利顺势加、亏损坚决减；永不对亏损单加仓。
- **多指标共振**：MA + 量能 + 动量 三共振才出手；单一指标易踩诱多。
- **固定风险单位**：每笔亏损 ≤ 总资金 1%–2%，按止损距离反推仓位。
- **环境/连亏熔断**：连续 3 次亏损或总回撤 >8% 停止交易。
> 系统对以上以「软引导」呈现：信号中标注风险等级与风控前置建议，由用户最终决策。

### 2.3 指标释义库（每个指标一句话专业解读，UI 悬浮提示 / AI 引用）
- 均线 MA：趋势方向与价格位置，短线生命线（5/10 日）。
- 量比/换手：活跃度与资金参与度验证。
- MACD：趋势动能与转折，抓启动/背离逃顶。
- 布林带 BOLL：波动边界、超买超卖、变盘预警。
- KDJ/RSI：短线超买超卖极值（单边市会钝化，须配合均线）。
- 箱体：高抛低吸与突破跟随的结构参考。

## 三、主要功能清单

### 1. 账户与安全管理
- 账号密码登录、会话管理（密码加盐哈希）
- 本地数据存储，隐私保护（行情/持仓/规则不出本机、不上未授权平台）
- 全局配置管理（数据源、通知、AI 密钥）

### 2. 行情数据管理（数据层模块）
- A 股日线行情拉取与本地缓存（akshare，免费起步；akshare 不可用时降级演示数据，保证可运行）
- 盘后/定时行情更新，保障时效
- 行业板块行情与趋势数据
- 通用技术指标计算：均线(MA)、量能(量比/换手)、MACD、布林带(BOLL)、KDJ/RSI、振幅、箱体

### 3. 选股模块（Screener 接口 · 含偏好驱动 + 方案类型）
- **投资偏好分析（AI 辅助）**：问卷 → 评分画像 → 关注指标采集 → **DeepSeek LLM 分析建议** → 匹配/生成选股方案（见第六节省"方案类型"）
- 可视化筛选条件：股价 < 30、周期内平均振幅 3–5%、箱体稳定微增、联动行业板块上涨等（全部参数化、可自定义）
- **模块接口**：`Screener.run(config) -> candidates`；内置实现 `RuleScreener`（规则筛选），预留 `MLScreener` 等扩展点
- 模型保存 / 启用 / 多模型管理；一键运行 → 候选 → 经接口推入短线可投池

### 4. 短线可投池与择时信号系统（核心：指标化、规律化、风险优先）
#### 4.1 短线可投池（用户自持）
- 手动加入 / 移除习惯跟踪的短线标的（也可由选股模块经接口推送）
- 标注成本价 / 仓位 / 备注；池内统一算指标、跑信号

#### 4.2 指标库（curated，普适有效）
1. 均线 MA（5/10/20/60）：趋势与位置。原语：排列/金叉死叉/上穿下穿/连续 N 日站上跌破/斜率。
2. 量能（量比/换手/量价配合）：验证趋势真伪。原语：量比>K、换手区间、放量缩量、价涨量增。
3. MACD（DIF/DEA/柱）：动能与转折。原语：金叉死叉、零轴上下、柱收敛放大、顶/底背离。
4. 振幅 / 布林带 BOLL：波动边界与超买超卖。原语：触上/下轨、带宽收窄(变盘)、振幅阈值。
5. KDJ 或 RSI（二选一）：短线极值。原语：金叉死叉、RSI>70/<30、钝化。
6. 箱体（支撑/压力）：高抛低吸与突破。原语：回踩支撑不破、放量突破压力、跌破支撑。

#### 4.3 信号模块（SignalEngine 接口 + 共振 + 风控软引导）
- **条件原语（AND/OR、优先级、作用范围）**：均线/量能/价格/动能/波动结构 共 13 类
- **多指标共振（置信度）**：单规则多条件 + 「共振组」——N 个独立指标同指一方 → 置信度提升、建议更明确
- **动作与风险前置（软引导）**：`add`/`reduce`/`alert`/`hold` + 可读 `reason` + **风险前置（风险等级、建议仓位上限、止损位）**；超阈值强预警但由用户决策
- **风控软引导**：硬性止损/止盈阈值仅作预警与建议，不强制拦截加仓
- **模块接口**：`SignalEngine.evaluate(pool, rules) -> signals`；内置 `RuleSignalEngine`，预留自定义引擎

### 5. 分析输出与跟踪中心（看板总览 + 分析中心 双视图）
#### 5.1 看板总览（Dashboard）— 风险优先、一目了然
- 顶部：**风险预警置顶**（强制止损/超阈值标的先报）+ 信号概览（今日 add/reduce/alert 计数）+ 可投池规模
- 卡片化：按 方案类型 / 行业 / 信号类型 聚合；大盘环境过滤提示
- 快速入口：进入任一标的「分析中心」

#### 5.2 分析中心（单标的详情）— 融合 3/4 结果、灵活跟踪
- 统一呈现：指标快照（MA/量能/MACD/布林/KDJ·RSI/箱体）+ 命中信号(风险等级/置信度) + 操作建议 + 风险前置(止损/仓位) + 跟踪历史
- 灵活交互：自定义列、按维度筛选；信号结果回测跟踪（命中后涨跌，用于自我优化）
- 风险偏好引导：给出建议时先呈现专业基础与风险前置，并提示用户确认自身风险偏好决策

#### 5.3 通知（Notifier 接口 · 软引导播报）
- 第三方转发起步（ServerChan/PushPlus，预留企业微信/邮件）
- **风险优先播报**：复盘消息先报风险再报机会
- 每日定时复盘 + 信号即时推送
- **模块接口**：`Notifier.send(channel, content)`；多实现可插拔

### 6. 专业建议基础与风险偏好引导（AI 模块 · AIProvider 接口）
- **第一期（偏好分析）**：选股建模调用 DeepSeek，结合画像+关注指标给建议
- **风险偏好引导（贯穿）**：系统给建议时先呈现专业基础与风险前置，并**引导用户确认自身风险偏好决策**（如"当前信号偏激进，你为稳健型，建议仓位上限 X%，是否确认？"）
- **第三期扩展**：对话式采集偏好、主动追问关注指标、个性化模型/规则推荐、复盘智能解读
- **模块接口**：`AIProvider.analyze(prompt, ctx) -> advice`；内置 `DeepSeekProvider`，预留通义/智谱/本地 Ollama

### 7. 系统管理与部署（后期）
- 远程访问（Cloudflare Tunnel 免费穿透）；迁云（Docker，云无关）；数据备份导出

## 四、分析模型方案类型（接口参数化实例 · 全面客制化）

> 方案类型不是写死的 5 个，而是对【选股接口 + 信号接口 + 风控接口】的参数化配置（JSON），落库后可改、可自建。

| 类型 | 风险等级 | 选股倾向(参数) | 规则集特征(信号接口参数) | 风控参数(软引导) |
|---|---|---|---|---|
| 稳健型 | 低 | 低波动、箱体稳定、流动性好 | MA 多头 + 量能温和 + 低换手；回避高波动 | 单只≤1.5成、止损3%、总仓≤4成 |
| 激进型 | 高 | 强势突破、动量强 | MACD 金叉 + KDJ 低位 + 放量突破 | 单只≤2成、止损5%、总仓≤6成 |
| 短线波段 | 中 | 振幅适中、箱体高抛低吸 | 布林带 + 回踩支撑 + 量价配合 | 单只≤2成、止损4%、总仓≤5成 |
| 低波动偏好 | 低 | 振幅 3–5%、平稳增长 | 均线斜率温和 + 振幅阈值 + 行业联动 | 单只≤2成、止损3%、总仓≤5成 |
| 自定义 | 用户定 | 用户全自定义 | 全开放 | 用户定 |

- 每个类型 = `ScreenerConfig` + `SignalRuleSet` + `RiskConfig` 三件套，注册为「方案类型」，可套用并微调。
- 用户可自建新类型：在设置/选股页填参数 → 落库 → 成为新方案类型，无需改代码。

## 五、附：明确不纳入的指标（及原因）
- 主力/北向资金流：免费数据口径不一、易被误导，依赖付费源 → 暂不入（二期有可靠源再评估）
- 筹码/股东户数：数据滞后、解释复杂 → 不入
- 江恩/斐波那契时间窗、玄学类：缺乏普适实证 → 不入
- 过多参数化 exotic 指标：易过拟合、难维护 → 不入
- 任何"必胜/高胜率"黑箱指标：与「辅助判断、规避风险」目标冲突 → 不入

## 七、技术落地要点（模块化解耦）
- 后端：`backend/app/services/` 下每个模块一个包，定义 `Protocol` 接口 + 内置实现；`routers/` 与编排层只依赖接口。
- 配置驱动：方案类型/规则/通知参数均为 JSON，存本地库，运行时加载，支持客制化与热替换。
- 前端：看板总览 + 分析中心双路由；设置页支持自建方案类型、配置通知与 AI 密钥。
- 隐私：仅对外拉行情 + 调你自己的 LLM/通知；其余全本地。
